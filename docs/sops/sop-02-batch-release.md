# SOP-QA-002 — Batch release

## Purpose
Define the sign-off chain that releases a manufactured batch for distribution.

## Chain of roles
Release requires three approvals in order: QA reviewer, QA manager, then the Qualified Person. A later role cannot sign while an earlier role's gate is failing.

## Reviewer criteria
The QA reviewer confirms there are no open critical deviations on the batch. Any open critical deviation blocks the chain immediately.

## Manager criteria
The QA manager confirms no CAPA linked to the batch's deviations is overdue. Overdue CAPAs indicate the quality system is not keeping pace and must be resolved first.

## Qualified Person criteria
The Qualified Person confirms the batch record is complete: no open deviations of any class remain. Only then is the batch released.

## Rejection
Rejecting a batch is a gated action: it requires the Qualified Person's documented decision and rationale, recorded in the audit log.
