# Security policy

## Supported versions
Only the latest `main` is supported. This is a synthetic-data demo project;
there is no production deployment.

## Reporting a vulnerability
Open a private security advisory on GitHub or contact the repository owner.
Do not open a public issue for a suspected vulnerability.

## Scope notes
- All data in this repo is synthetic and fictional.
- The SELECT-only gateway, PII scrubbing, and audit chain are the primary
  security controls; see `docs/threat-model.md`.
